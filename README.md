# Northwind-Traders-End-to-End-Power-BI-Project
An end-to-end Business Intelligence project analyzing global sales and financial performance using Power BI. The project covers the complete workflow: data loading, cleaning and transformation in Power Query, data modeling, DAX measures, and interactive dashboards that provide insights into revenue, profitability, regional performance, product performance, customer segments, and financial trends.
